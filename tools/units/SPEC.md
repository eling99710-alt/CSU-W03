# 稀釋與單位換算器（Dilution & Unit Converter）專用規格書

本規格書定義「我的實驗室工具箱」擴充小工具——**「稀釋與單位換算器」**之計算邏輯、資料清洗規則、防呆機制與介面呈現標準。本工具遵循專案根目錄 [SPEC.md](file:///d:/CSU%20W03/SPEC.md) 之共同規範，採純前端無伺服器（100% Client-side）運算，確保樣品資料機密性。

---

## 1. 工具基本資訊與目標

- **工具識別碼（Tool ID）**：`units`
- **工具名稱**：稀釋與單位換算器（Dilution & Unit Converter）
- **所屬分類**：樣品前處理與配製（`prep`）
- **核心目標**：
  - 解決微量分析（如 ICP-MS、AAS、ICP-OES）上機數據中單位混雜（`ug/L`, `mg/L`, `ppm`, `ppb`, `ng/mL`）、編碼不一（`µg/L` 與 `ug/L`）與髒資料問題。
  - 依據不同基質（水樣、土壤、食品）的前處理物理特徵，自動分流套用對應公式，一鍵換算為符合法規要求的報告濃度（水樣報 $\mu\text{g/L}$，土壤乾基報 $\text{mg/kg}$，食品報 $\text{mg/kg}$）。

---

## 2. 輸入資料規範與欄位對應

### 2.1 支援輸入方式
1. **檔案上傳**：支援拖曳或選取 `.csv`, `.xlsx`, `.xls` 檔案（例如 `sample_results.csv`）。
2. **Excel 貼上**：支援從 Excel 選取整欄/整表直接貼上（`Ctrl + V`），自動解析 Tab 分隔字元。
3. **載入範本**：提供「示範檢驗資料集」便於新進同仁快速體驗與驗證。

### 2.2 欄位對應與解析規則
系統讀取檔案時，欄位映射與前置清洗規則如下：

| 原始欄位名稱 | 型別 | 必要性 | 欄位意義與清洗規則 |
| :--- | :---: | :---: | :--- |
| **樣品編號** | 字串 | 必要 | 樣品唯一識別碼。**系統自動去除首尾空格（`.trim()`）**。 |
| **樣品類型** | 字串 | 必要 | 基質類別：`水樣`、`土壤`、`食品`。決定計算分流邏輯。 |
| **元素** | 字串 | 必要 | 待測分析物金屬名稱（如 `Pb`, `Cd`, `As`, `Cu`, `Cr`, `Ni`, `Zn`, `Hg`）。 |
| **上機濃度** | 數值 | 必要 | 儀器直接測得之數值。若為空值則標記為「缺失值」。 |
| **單位** | 字串 | 必要 | 上機濃度之計量單位。由單位正規化引擎進行解析與轉換。 |
| **稀釋倍數** | 數值 | 選填 | 檢液稀釋倍率。若未填或空值，預設為 `1`。 |
| **定容體積 (mL)** | 數值 | 固體必要 | 固體消化定容體積（$V$）。水樣自動忽略此欄。 |
| **樣品重 (g)** | 數值 | 固體必要 | 固體秤樣重（$W$）。水樣自動忽略此欄。 |
| **含水率 (%)** | 數值 | 土壤選填 | 土壤乾基校正用水分含量。若原檔無此欄，**預設為 $0\%$** 並允許同仁在介面線上補填。 |

## 3. 單位正規化引擎（Unit Normalization）

為了消除儀器軟體匯出時單位字串紛亂之問題，系統將所有上機濃度統一正規化轉換為 **基準單位：$\mathbf{\mu\text{g/L}}$**（假定水相酸性檢液密度 $\rho \approx 1.0\text{ g/mL}$）：

| 原始單位寫法（不分大小寫與首尾空白） | 歸一化倍率（乘上係數轉為 $\mu\text{g/L}$） | 備註說明 |
| :--- | :---: | :--- |
| `ug/L`、`UG/L` | $\times 1.0$ | 標準微克/公升 |
| `µg/L` (Unicode `U+00B5` 微米符號) | $\times 1.0$ | 自動相容特殊 Unicode 微米符號 |
| `mg/L`、`MG/L` | $\times 1000.0$ | $1\text{ mg/L} = 1000\ \mu\text{g/L}$ |
| `ppb`、`PPB` | $\times 1.0$ | 水相溶液微克級無因次比率（$1\text{ ppb} \approx 1\ \mu\text{g/L}$） |
| `ppm`、`PPM` | $\times 1000.0$ | 水相溶液毫克級無因次比率（$1\text{ ppm} \approx 1\text{ mg/L} = 1000\ \mu\text{g/L}$） |
| `ng/mL`、`NG/ML` | $\times 1.0$ | $1\text{ ng/mL} = 1\ \mu\text{g/L}$ |
| *其他未定義字串* | 無法轉換 | 標記「單位無法辨識」，該列暫停計算並亮警示標籤 |

## 4. 各基質之計算公式與演算法

設：
- $C_{\text{raw}}$：原始上機濃度數值
- $f_{\text{unit}}$：單位正規化轉換係數（轉為 $\mu\text{g/L}$ 之乘數）
- $C_{\text{norm}} = C_{\text{raw}} \times f_{\text{unit}}$：上機標準化濃度（$\mu\text{g/L}$）
- $DF$：稀釋倍數（Dilution Factor，預設 1）
- $V$：定容體積（$\text{mL}$）
- $W$：樣品重（$\text{g}$）
- $M\%$：含水率百分比（Moisture %，範圍 $0 \le M\% < 100$）

### 4.1 水樣（液體基質）
- **報告單位**：$\mathbf{\mu\text{g/L}}$
- **計算公式**：
  $$C_{\text{report}} (\mu\text{g/L}) = C_{\text{norm}} (\mu\text{g/L}) \times DF$$
- **規則**：水樣直接進樣或純稀釋，**完全不讀取也不依賴 $V$ 與 $W$**，即使該兩欄為空值亦不影響計算。

### 4.2 土壤（固體環境基質——乾基校正）
- **報告單位**：$\mathbf{\text{mg/kg}}$（乾基基準）
- **推導過程**：
  - 金屬總微克數：$\text{Total } \mu\text{g} = C_{\text{norm}} (\mu\text{g/L}) \times DF \times \frac{V(\text{mL})}{1000\text{ mL/L}}$
  - 金屬總毫克數：$\text{Total mg} = \frac{\text{Total } \mu\text{g}}{1000\ \mu\text{g/mg}}$
  - 樣品乾重（公斤）：$W_{\text{dry}} (\text{kg}) = \frac{W (\text{g}) \times (1 - M\% / 100)}{1000\text{ g/kg}}$
- **最終計算公式**：
  $$C_{\text{report}} (\text{mg/kg}) = \frac{C_{\text{norm}} (\mu\text{g/L}) \times DF \times V (\text{mL})}{W (\text{g}) \times 1000 \times \left(1 - \frac{M\%}{100}\right)}$$
- **規則**：若匯入資料無含水率欄位，系統預設 $M\% = 0$（即未校正前之濕基值），並在介面提供線上調整輸入格與提示標註。

### 4.3 食品（固體生物基質——法規常規濕重基準）
- **報告單位**：$\mathbf{\text{mg/kg}}$（鮮重/濕重基準，符合衛生福利部食品重金屬限量標準）
- **計算公式**：
  $$C_{\text{report}} (\text{mg/kg}) = \frac{C_{\text{norm}} (\mu\text{g/L}) \times DF \times V (\text{mL})}{W (\text{g}) \times 1000}$$
- **規則**：需備齊定容體積 $V$ 與樣品重 $W$。

## 5. 髒資料清洗、驗證與防呆機制

系統在處理每一筆數據時，嚴格依循下列防呆檢核流程，**絕不因單筆資料錯誤而導致整體程式中斷**：

| 檢核情境 | 觸發條件 | 系統處置行為 | 狀態標籤 (Badge) | 匯出備註 |
| :--- | :--- | :--- | :---: | :--- |
| **編號帶空格** | 樣品編號首尾含 ASCII/全形空白 | 自動執行 `.trim()` 清洗字串 | 正常 (綠) | - |
| **數值缺失** | 上機濃度為空值、空白字元或非數值 | 不進行數學計算，跳過此筆 | 🔴 數值缺失 | 原始資料缺少上機濃度 |
| **未定義單位** | 單位不在正規化字典中 | 不進行換算 | 🔴 單位未知 | 單位格式無法辨識 |
| **固體缺定容/秤重** | 樣品為土壤或食品，但 $V$ 或 $W \le 0$ 或為空 | 停止固體換算，避免除以零 | 🔴 前處理不全 | 缺少定容體積或樣品重 |
| **土壤未填水分** | 樣品為土壤，原檔無含水率 | 預設以 $0\%$ 計算，介面開放編輯 | 🟡 濕基(水=0%) | 未輸入含水率，以濕基計算 |
| **水分過大防呆** | 土壤含水率 $M\% \ge 100\%$ | 提示數值不合理，避免除以零或負數 | 🔴 含水率異常 | 含水率需小於 100% |

## 6. 使用者介面規格（UI / UX Standards）

依據工具箱共同規格，採用標準三段式響應式版面：

### 6.1 頂部導覽區（Header Section）
- 工具主標題：「稀釋與單位換算器」、副標題簡介。
- **「SOP / 計算原理」按鈕**：點擊彈出 Modal 彈窗，提供：
  - 各基質標準檢驗法規引述（環境部 NIEA、衛福部食藥署 TFDA 標準方法）。
  - 水樣、土壤乾基、食品公式說明與單位對照推導。
  - 操作常見問題與髒資料清洗範例。

### 6.2 主作業區（Workspace Section）
1. **輸入與操作控制區**：
   - 拖曳式檔案上傳區（支援 `.csv`, `.xlsx`）。
   - 「從 Excel 貼上」按鈕（彈出預覽貼上視窗）。
   - 「載入範本資料」按鈕（快速載入 `sample_results.csv` 測試資料）。
   - 小數點位數自訂選擇器（2、3、4 位小數切換）。
2. **總覽統計 KPI 卡片**：
   - 總樣品數、換算成功筆數、異常/缺值筆數。
3. **基質篩選頁籤（Category Filter Tabs）**：
   - 【全部樣品】、【水樣】、【土壤】、【食品】、【僅看異常樣品】。
4. **互動式計算結果資料表**：
   - 欄位包含：`樣品編號`、`樣品類型`、`元素`、`原始濃度`、`原始單位`、`稀釋倍數`、`定容 V`、`樣品重 W`、`土壤含水率 % (可線上即時修改並自動重算)`、`★ 報告濃度`、`報告單位`、`狀態標籤`。
   - 報告濃度欄以粗體高對比色彩突出顯示。

### 6.3 底部操作功能列（Action Toolbar）
- **一鍵複製文字報告**：產生格式化 Markdown / 純文字清單，便於貼入電子實驗紀錄本（ELN）。
- **匯出 Excel (`.xlsx`)**：
  - Sheet 1：完整成果報告（含原始欄位、換算標準化因子、最終報告濃度、報告單位與備註）。
  - Sheet 2：異常樣品清冊（列出所有缺值與需補件之樣品）。
- **匯出 CSV**：UTF-8 編碼 CSV 下載。
- **清空重設按鈕**：含防誤觸確認對話框。

## 7. 狀態持久化規範

- **自動草稿記憶**：使用者上傳之數據與手動修改之含水率數值，即時存入瀏覽器 `localStorage`（鍵名：`lab_tool_units_draft`），重新整理網頁不遺失進度。
- **一鍵清空**：點擊清空按鈕時，清除對應 localStorage 暫存並還原初始狀態。
