# 多批次結果彙整與品管查核器（Multi-Batch Merger & QA/QC Checker）專用規格書

本規格書定義「我的實驗室工具箱」擴充小工具——**「多批次結果彙整與品管查核器」**之資料對齊邏輯、法規比對標準、超標判定規則與介面產出規範。本工具遵循專案母規格 [SPEC.md](file:///d:/CSU%20W03/SPEC.md) 之共同規範，採純前端無伺服器（100% Client-side）運算，確保多批次檢驗數據之機密性。

---

## 1. 工具基本資訊與目標

- **工具識別碼（Tool ID）**：`merge`
- **工具名稱**：多批次結果彙整與品管查核器（Multi-Batch Merger & QA/QC Checker）
- **所屬分類**：品管與數據彙整（`qa-qc`）
- **核心目標**：
  - **跨批次資料對齊**：解決不同週次、不同分析員匯出檔案中欄位名稱不同（如 `Sample ID` vs `SampleID`、`Matrix` vs `基質`）與農藥名稱大小寫不一（如 `Carbofuran` vs `CARBOFURAN`）的格式混亂問題。
  - **自動法規查核**：自動比對農藥殘留容許量標準（`pesticide_limits.csv`），精準判讀「`<LOQ` 未檢出」、「合格」與「🔴 超標」。
  - **品管成果產出**：即時產出「超過容許量清單」與「樣品檢出矩陣表（Pivot Table）」，一目了然掌握多重農藥殘留現況。

## 2. 異質欄位映射與別名字典（Column Aliases）

系統在讀取各批次檔案時，自動啟用「智慧欄位對照引擎」，將異質欄位統合成內部標準資料模型：

| 內部標準欄位 | 說明 | 相容之原始欄位名稱（大小寫不敏感、忽略空格） |
| :--- | :--- | :--- |
| `batchId` | 批次來源 / 日期 | 自動從檔案名稱擷取（如 `batch_20260920` $\rightarrow$ `2026-09-20`）或由同仁指定 |
| `sampleId` | 樣品編號 | `Sample ID`, `SampleID`, `樣品編號`, `樣品 ID`, `ID` |
| `matrix` | 樣品基質 / 蔬菜品項 | `Matrix`, `基質`, `樣品類型`, `蔬菜`, `品項` |
| `analyte` | 化合物 / 農藥名稱 | `Analyte`, `化合物`, `農藥名稱`, `分析物`, `Compound` |
| `area` | 待測物層析面積 | `Area`, `Peak Area`, `面積`, `待測物面積` |
| `isArea` | 內標（ISTD）面積 | `IS Area`, `ISTD Area`, `內標面積`, `ISTD` |
| `calcConc` | 檢出濃度 (mg/kg) | `Calc Conc (mg/kg)`, `Conc. mg/kg`, `濃度`, `定量濃度`, `Conc` |

### 2.1 農藥名稱大小寫正規化
農藥比對一律採**大小寫不敏感（Case-Insensitive）**模式，並統一格式化為標準首字大寫：
- `CARBOFURAN` / `carbofuran` $\rightarrow$ `Carbofuran`（加保扶）
- `IMIDACLOPRID` / `imidacloprid` $\rightarrow$ `Imidacloprid`（益達胺）
- `ACETAMIPRID` / `acetamiprid` $\rightarrow$ `Acetamiprid`（亞滅培）
- `CHLORPYRIFOS` / `chlorpyrifos` $\rightarrow$ `Chlorpyrifos`（陶斯松）
- `FIPRONIL` / `fipronil` $\rightarrow$ `Fipronil`（芬普尼）

## 3. 法規容許量比對與品管判定標準

### 3.1 內建示範容許量標準庫（`pesticide_limits.csv`）
系統預設內建下列 5 種常見農藥之標準值，亦支援使用者上傳自訂標準檔：

| 農藥英文名 (Analyte) | 中文常用名 | 示範容許量 (mg/kg) | 定量極限 LOQ (mg/kg) | 說明與法規特點 |
| :--- | :---: | :---: | :---: | :--- |
| **Carbofuran** | 加保扶 | **0.02** | 0.01 | 氨基甲酸鹽類殺蟲劑，毒性高，標準嚴格 |
| **Imidacloprid** | 益達胺 | **0.5** | 0.01 | 新菸鹼類殺蟲劑，廣泛使用，容許量較寬 |
| **Acetamiprid** | 亞滅培 | **0.2** | 0.01 | 新菸鹼類殺蟲劑 |
| **Chlorpyrifos** | 陶斯松 | **0.05** | 0.01 | 有機磷類殺蟲劑 |
| **Fipronil** | 芬普尼 | **0.005** | 0.01 |  phenylpyrazole 類；**法規容許量 (0.005) 低於儀器 LOQ (0.01)** |

### 3.2 超標與合規判定邏輯（QA/QC Criteria）
針對每一筆檢驗數據（設檢出值為 $C$，法規容許量為 $L$，定量極限為 $LOQ$）：

1. **「&lt;LOQ」判定**：
   - 當原始欄位為字串 `<LOQ`、`ND` 或數值小於 $LOQ$ 時，**一律判定為「🟢 合格（未檢出）」**。
   - *特別備註*：針對芬普尼（$L = 0.005 < LOQ = 0.01$），在現行檢驗實務上，低於定量極限時無法定量，依標準法規報告為未檢出，視為合規。
2. **數值檢出判定**：
   - **$C > L$（超標）**：判定為「**🔴 超標 (FAIL)**」，系統將此項目自動納入【超過容許量清單】。
     - **超標倍數**：$\text{Ratio} = \frac{C}{L}$（保留 2 位小數，如檢出 0.6084、限量 0.5，超標倍數為 $1.22\times$）。
   - **$LOQ \le C \le L$（檢出且合格）**：判定為「**🟡 檢出未超標**」，代表有農藥殘留但未違反法規上限。
3. **未登錄之農藥**：
   - 若批次中出現未在標準表中的農藥，判定為「⚪ 未列標準」，提示同仁手動查核。

## 4. 介面設計與雙檢視總表規範

遵循工具箱母規格的三段式版面：

### 4.1 頂部導覽列（Header Section）
- 標題：「多批次結果彙整與品管查核器」、副標題簡介。
- **「SOP / 法規與比對原理」按鈕**：點擊跳出 Modal 彈窗，清楚列明：
  - 農藥殘留容許量法規標準來源與衛福部食藥署公告。
  - `<LOQ` 判定準則與芬普尼特殊極限說明。
  - 多批次欄位正規化對齊規則與常見問題處置。

### 4.2 主作業區（Workspace Section）
1. **多檔操作與載入列**：
   - **多批次上傳區**：支援按住 `Ctrl` 或框選一次拖曳多個批次 CSV/Excel。
   - **自訂標準表上傳**：可上傳自訂 `pesticide_limits.csv`。
   - **「載入三週示範批次」按鈕**：一鍵將 0920、0927、1004 三週共 90 筆數據直接載入驗證。
2. **品管 KPI 統計卡片**：
   - 總檢測項目數（例：90 項）
   - 涵蓋批次數（例：3 週批次）
   - 違規超標項目數（例：8 筆超標）
   - 違規樣品數（例：5 顆蔬菜樣品超標）
   - 違規率（%）
3. **【超過容許量清單】（最優先注目區塊）**：
   - 集中展示所有判定為「🔴 超標」的項目（示範資料共 8 筆）：
     - 批次來源、樣品編號、蔬菜基質、超標農藥、檢出濃度、法規容許量、超標倍數、警示標籤。
4. **【彙整總表】雙檢視切換（Dual-View Toggle）**：
   - **檢視 A：明細長表（Long Table，共 90 筆）**：
     - 包含所有批次原始數據、面積比、檢出濃度、比對標準與判定標籤。支援基質（小白菜/番茄/高麗菜）與農藥即時搜尋篩選。
   - **檢視 B：樣品矩陣寬表（Pivot Table，共 18 筆蔬菜）**：
     - 以「樣品編號 + 蔬菜基質」為列，橫向展開 5 種農藥欄位。
     - **超標儲存格自動以紅底粗體標註**，合格檢出以黃底標註，`<LOQ` 顯示灰色。
     - 清楚識別「多重農藥殘留雞尾酒效應」（例如 V305 番茄同時超標 3 種農藥）。

### 4.3 底部操作功能列（Action Toolbar）
- **一鍵複製超標通報**：產生格式化 Markdown 文字，包含超標件數、違規樣品清單與超標倍數，便於貼入電子實驗紀錄本（ELN）或主管報告。
- **匯出完整 Excel（`.xlsx` 多工作表）**：
  - **Sheet 1【超標違規清單】**：所有超出容許量之品項與超標倍數。
  - **Sheet 2【農藥殘留矩陣寬表】**：18 筆蔬菜樣品對應各農藥之 Pivot 矩陣。
  - **Sheet 3【多批次彙整明細總表】**：90 筆標準化明細總表。
- **匯出 CSV**：下載彙整明細總表 CSV。
- **清空重設按鈕**：含防誤觸確認。
